# NBACAB

NBA Coffee & Burritos — a visual NBA roster, stats, salary and CBA playground.

## Current starter

This first build includes:

- React + Vite
- React Router
- All 30 NBA teams on the home page
- Clickable team routes such as `/team/lal` and `/team/sas`
- A visual PG / SG / SF / PF / C team-page shell
- Responsive styling
- No API key or private data committed to GitHub
